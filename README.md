
# Experiment 6: Responsive Lifestyle Blog Website

## Aim
To build a responsive blog website using Bootstrap and CSS media queries that adapts to different screen sizes.

## Description
The Everyday Edit is a simple lifestyle blog website created using HTML, CSS and Bootstrap 5. It shares content related to everyday living, wellness, travel and food.

The website uses Bootstrap components and CSS media queries to provide a responsive layout for desktops, tablets and mobile devices.

## Features
- Responsive navigation bar.
- Attractive hero section.
- Blog cards with images and descriptions.
- About section.
- Responsive layout for different screen sizes.
- Hover effects on blog cards.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- CSS Media Queries

## Files Included
- index.html – Contains the complete structure, styling and Bootstrap integration of the website.

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. View the website on desktop or mobile screen sizes.

## Outcome
Successfully developed a responsive lifestyle blog website using Bootstrap and CSS media queries. The website adapts its layout to different screen sizes.
